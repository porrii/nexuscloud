# Manuales de usuario

Documentación para instalar, administrar y usar NexusCloud — sin
necesitar leer el código. Si buscas arquitectura, decisiones de diseño o
la referencia técnica de la API HTTP, eso vive en
[`nexuscloud/docs/`](../nexuscloud/docs/) en su lugar.

- **[Primeros pasos](primeros-pasos.md)** — de `install.sh` al primer
  login, en un servidor Linux sin entorno gráfico.
- **[Referencia de comandos](comandos.md)** — todo el CLI, con ejemplos
  reales de cada subcomando.
- **[Administración](administracion.md)** — usuarios, grupos, doble
  factor (TOTP).
- **[Backup y recuperación](backup-y-recuperacion.md)** — manual,
  programado, incremental, cifrado, a otro servidor.
- **[Cliente de escritorio](cliente-de-escritorio.md)** — instalar,
  configurar pares de sincronización, qué hacer ante un conflicto.
- **[Mantenimiento](mantenimiento.md)** — comprobar el estado, logs,
  actualizar, añadir/quitar la web, desinstalar, problemas frecuentes.
- **[Preguntas frecuentes](preguntas-frecuentes.md)**.

Todo aquí se ha probado de verdad contra un servidor real antes de
documentarlo — si algo no coincide con lo que ves en tu instalación,
puede que estés en una versión distinta; revisa `nexuscloud version`.
